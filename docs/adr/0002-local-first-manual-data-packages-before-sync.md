# 本地优先并先支持手动数据包

晷迹第一期采用本地优先策略：没有账号、网络或原生云同步时，用户也能完整使用 Day Todo、日轨迹、延续复制、每日复盘等核心功能。第一期只提供手动导出和导入数据包，并在设置中预留同步端点入口；不做自动双向同步，也不直接把裸 SQLite 数据库文件放进 iCloud、Dropbox 或 S3 之类的同步位置。

**Consequences**

- 领域数据模型和持久化层必须从第一天考虑未来同步，保留稳定 ID、版本、设备来源和可重放变更记录。
- 自动云同步、冲突合并、原生账号和对象存储同步放到后续阶段。
- 数据交换应面向可校验的数据包或事件包，而不是复制数据库文件。
