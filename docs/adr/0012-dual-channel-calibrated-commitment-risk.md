# 承诺风险采用本地基准与 LLM 情境判断双通道

晷迹不让 LLM 直接生成正式兑现概率，也不把稀疏本地历史包装成完整世界模型。**承诺风险计算器** 使用可复算规则输出个人 reference class、样本、概率区间与证据资格；**LLM 情境判断** 补充任务语义、依赖、范围和当前约束，两者先并列形成 **双通道承诺风险**。

**Consequences**

- 本地基准可以输出证据不足，LLM 不得将其升级成确定概率。
- 未经前瞻性后验校准，LLM 只能列出情境风险、依据、假设和反例。
- 未校准配置可以生成 **实验概率** 供后验验证，但主决策界面不展示该数字，也不允许它影响正式建议；用户可在校准与审计面板主动查看。
- 每次预测必须保存输入、Provider、模型、prompt／算法版本、原始本地结果、LLM 判断、用户采用方案和日后真实结果。
- 只有经真实结果证明校准，并且持续优于纯本地基准的模型版本，才可参与正式综合概率。
- 获得资格后仍须由用户授予 **综合概率授权**；模型失准或预测配置实质变化时自动暂停，不能由用户强制伪装为正式科学结果。
- 即使未来启用综合概率，界面仍必须分别展示本地基准、LLM 调整因素、综合结果和历史校准表现。
