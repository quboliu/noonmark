# 烛龙极简首页原型

> THROWAWAY PROTOTYPE — 三个烛龙首页变体通过既有 `noonmark-mac-prototype.dc.html` 的 `?variant=A|B|C` 切换。用户确认信息层级后，结论应重写为正式 SwiftUI，原型与切换器必须删除。

## 要回答的问题

用户进入烛龙首页后，能否立即知道：可以做什么、哪些事情正在等待自己、下一步是什么？

## 共同产品边界

- 首页保留一个自然语言主入口，并在其下方用单层列表展示任务成形、每日收尾两个固定工作流；排期与分类作为较弱层级的专项助手，不使用一排“生成”按钮或 Dashboard 卡片。
- 固定入口以用户结果命名，并直接建立对应的有界会话，不再只把示例文案填回输入框。
- 首页不展示 Provider 配置、权限 profile、默认可见范围、YOLO、记忆管理或系统边界说明；这些属于设置。
- 实际使用范围、记忆和远程 Provider 只在动作即将使用时按情境披露。
- 删除“草稿收件箱”。只有确实等待用户动作或可以恢复的会话出现在首页；草稿、简报与 diff 留在所属会话流中。
- 每个等待项都必须同时说明“现在是什么状态”和“用户下一步做什么”，禁止只写“继续”“生成”“打开”。
- 烛龙事件历史保留轻量入口，但不与主动作争抢层级。

## 像素级 prompt

- 唯一外框来自当前 Noonmark Mac App：`1320 × 820` 逻辑窗口、`240px` sidebar、冷灰亮色主题、系统字体。不得复刻 ChatGPT 品牌、网页 toolbar 或 Scheduled 业务语义。
- 窗口背景 `#FDFDFC`，sidebar `#FAFAF9`，panel `#FFFFFF`，次 panel `#FBFBFC`；普通线 `#E6E6E9`，强调线 `#CCCCD5`。
- 正文 `#1C1C1F`，次文 `#6B6B75`，弱文 `#A1A1AB`；主交互 `#2961C7`，soft accent `#EDF4FF`。`#7C5CFF` 仅用于烛龙导航图标及极淡标记。
- PageHeader 水平 `24px`、垂直 `16px`；标题 `21px/700`，副标题 `12px`。正文区域 padding `20px 24px 32px`，最大阅读宽度按变体控制在 `760–900px`。
- 主输入高 `58–68px`，圆角 `9px`，`1px #D8D8DE` 边界；聚焦时只使用 `2px rgba(41,97,199,.10)` 外环。输入文本 `13px`，placeholder `#A1A1AB`。
- 常规行高 `62–72px`，圆角 `8px`；标题 `12.5–13px/600`，状态与下一步 `10.5–11.5px`。主要动作沿用当前 App 小按钮，不使用大面积蓝色实心按钮。
- 页面只允许一个大视觉重心。禁止 dashboard card grid、统计 tile、常驻右侧“系统边界”、权限 chip 海洋和多组重复标题。
- 参考图只借鉴“标题 → 一句话解释 → 单一输入 → 稀疏列表”的层级、留白和可扫描性。
- 原型切换器固定在窗口底部中央：黑色组件级 pill，显示 `A/B/C + 方案名`，左右箭头循环；输入聚焦时不截获方向键。它不是产品 UI。

## 三种结构

### A — 单列指令台

主输入占据第一视觉层级；下面先显示 3 个结果型示例，再显示“待你决定”的稀疏列表。它最接近参考图，问题是等待事项可能位于首屏稍下方。

### B — 下一件事

若存在等待用户决定的事项，首页先展示唯一一个最紧迫决定及其依据摘要；自然语言入口收敛成紧凑输入，其他会话进入次级列表。它最能回答“下一步是什么”，风险是新任务发现性略弱。

### C — 决定分栏

左侧是自然语言入口与结果示例，右侧 `300px` rail 只显示“待你决定”。它利用 Noonmark 已有 Detail Rail 语法，让用户工作与烛龙产物分开；风险是空队列时右栏可能显得多余，因此空态必须自动退化为单列。
