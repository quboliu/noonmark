# 晷迹 Mac UI 设计契约

本文记录晷迹当前唯一的 Mac UI 实现契约。要求来自用户即时确认、真实 SwiftUI 运行产物与代码化 `NoonmarkMacUIContract`；归档 HTML 原型只保留设计来源，不是 ground truth。Mac 端实现必须逐项落实，不能遗漏、糊弄或暗改。

## 全局窗口与视觉

- macOS 窗口外壳：traffic lights 必须集成在侧栏顶部，不得额外渲染全宽顶部“额头”；三色按钮必须可操作关闭、最小化和缩放；窗口必须支持系统级拉伸调整尺寸；红色关闭按钮只关闭窗口，不退出 app，重新点 Dock 图标必须能恢复主窗口；真正退出必须走 `Cmd+Q` 或菜单“退出晷迹”；应用时钟 Logo、浅色桌面背景、白色/浅灰内容基底必须保留。窗口外缘必须有独立的可辨认发丝线，在白色桌面背景上能清楚读出窗口边界，但不得恢复外层深色方框或重阴影。
- 系统窗口标题必须从当前页面和选中日期派生，供 macOS 与 E2E 识别；视觉标题不得以独立全宽 titlebar 占用内容顶部空间。Day Todo 与日历页显示当前选中日期，不得硬编码为固定应用名。
- 主窗口尺寸基准：用户已确认当前唯一的紧凑密度；默认启动窗口为 `1200×768`，最小窗口为 `960×720`。默认宽度确保右侧详情栏展开后中栏仍保留约 `700pt`；不设置虚假的最大内容尺寸，窗口继续支持系统拉伸。
- 通用右侧 Detail Rail 默认收起，并由 Sidebar 品牌区的 `sidebar.right` 图标切换。展开或收起只重新分配中栏与 `280pt` 右栏的宽度，不得改变窗口总宽高；选中任务时自动展开，避免损失“点任务查看详情”的既有路径。
- 主题：`冷灰` 与 `微暖纸感` 两套外观。
- 语言：中文与 English 两套文案入口。
- 全局动效：日期 strip 选中态平滑移动、toast rise 动效、hover 高亮。
- 全局颜色语义：accent、ok、warn、chip、panel、line、windowBoundary、t1/t2/t3。
- Todoist 参考审美：只迁移统一浅色、低分割、轻控件和线性列表密度，不复刻 Todoist 的信息架构或品牌色。
- 主窗口、侧栏、主列表和详情栏必须像一个连续的浅色工作台；避免强阴影、强边框和大面积卡片堆叠把界面切成多个孤立面板。
- 通用输入、分段控件、筛选/操作按钮必须使用低对比浅底和发丝线边界；hover 只做轻微底色变化。
- 任务行、池化行、未来计划行、未完成行、已完成行和日历详情行优先使用线性列表分隔；默认态不得回到重卡片边框。
- 状态样式必须使用共享映射：待完成使用 accent/accent-soft，已完成使用 ok/ok-soft，未完成使用 warn/warn-soft，已延续、已变更、已回池使用 chip/t2，已废弃使用 chip/t3；任务行、日历、详情栏和轨迹时间线不得各自定义状态颜色。未完成状态色必须使用共享 `Theme.warn` / `Theme.warnSoft`，不得混用侧栏未完成导航橙色。
- 列表选中态必须使用 accent/accent-soft，不得被任务状态色覆盖；状态色只用于 glyph、chip、进度和轨迹节点。
- 非编辑态完成进度必须使用确定性自绘进度条，100% 使用 ok 绿色，避免 macOS 系统 `ProgressView` 把完成态渲染成灰色。
- 右键菜单、日期选择弹窗、变更任务弹窗、toast 都是必需交互。
- 以上窗口尺寸、颜色语义和全局动效都必须进入 `NoonmarkMacUIContract`，不能只停留在视觉说明里。

## 左侧导航

导航分组必须保留：

- `计划`
  - `Day Todo`，显示今天待完成数量。
  - `任务池`，显示任务池数量。
  - `未来计划`，显示未来计划数量。
- `轨迹`
  - `未完成`，显示未完成任务链数量。
  - `已完成`，显示完成记录数量，包含子任务完成记录。
  - `日历`。
  - `烛龙`，进入可选 sidecar，不影响普通清单能力；只有设置中“启用烛龙”开启时才显示。
- 底部 `设置`。

导航项必须有图标、选中背景、左侧选中条、计数胶囊和 hover 反馈。
导航图标必须保留当前页面语义色，不得被选中态或统一文字色覆盖：Day Todo `#2A6FDB`、任务池 `#0E9488`、未来计划 `#7C5CFF`、未完成 `#E0851B`、已完成 `#1F8A5B`、日历 `#D1477A`、烛龙 `#7C5CFF`、设置 `#64748B`。
导航选中态必须是安静浅色 pill：背景使用当前页面语义色的低透明度，文字回到主文本色，语义色主要留给图标和左侧选中条。
关闭“启用烛龙”时，左侧导航必须隐藏烛龙入口；若当前停留在烛龙页，必须自动切回可见页面。
关键操作按钮必须保护完整文案宽度，例如“从任务池排期…”不得被截断成省略号。

## Day Todo 页面

必须包含：

- 日期标题、星期、今日/历史已锁定/未来 badge。
- 上一天、今天、下一天、选日期按钮。
- 14 天日期 strip，含星期、日期、今天描边、选中圆点、任务存在点。
- 今天描边、选中圆点、任务存在点必须作为日期 strip 的独立契约点保留，不能被泛化成一个日期条组件后遗漏。
- 日期 strip 的视觉选中 pill 和全局平滑移动动效是两个契约点：前者属于 Day Todo 元素，后者属于全局动效。
- 日期 strip 选中 pill 必须是容器级独立滑动层，按 14 天 strip 的选中 index 平移；日期格子只负责文字、今天描边和任务存在点，不能退化为每个格子各自绘制本地选中圆。
- 点击日期 strip 中任一日期后，该日期区域必须成为原生 first responder；左 / 右切换前后一天，上 / 下切换前后一周，且不得依赖系统“键盘导航”偏好开关。
- 历史日锁定提示：任务事实不可改写，可补写复盘；未完成任务可延续或废弃。
- 未来日提示：可排期与调整顺序，不能提前完成或生成复盘。
- 当前日和未来日的快速新增输入。
- 从任务池排期按钮。
- 任务行：选择态、状态圆点、标题、进度条、延续/持续/变更/回池元信息、子任务展开、状态 chip、上下移动按钮。
- 任务行的选择态、状态圆点、标题、轨迹元信息和上下移动按钮必须作为独立契约点保留。
- 被变更的任务必须显示目标任务标题，并提供跳转到目标日轨迹的入口；不得只显示“被变更为新任务”这类无目标文案。
- 当日优先级控件表达领域里的当日优先级；任务行上下移动按钮是该控件在列表行中的视觉入口，两者都必须有实现映射。
- 空状态插图与文案。
- 所有空状态都必须同时保留插图和文案，不能只显示一个空容器。
- Day Todo、任务池、未来计划、未完成池、已完成池和日历的空状态都必须分别保留插图与文案契约点。

任务行交互必须包含：

- 当前日待完成且无子任务时可点击圆点完成。
- 当前日/未来日待完成可通过上下按钮调整当日优先级。
- 右键菜单与详情页三点菜单共享动作。
- 任务行只保留完成状态、子任务展开、优先级和已延续任务的当前轨迹跳转等高频直接操作；排期、改期、延续、废弃、回池、复制、历史日期跳转和删除等低频动作统一进入右键菜单，详情页不得再用独立操作区重复同一组动作。
- 右键菜单必须按页面、日期、状态和子任务情况过滤动作：当前待完成可延续、变更、回池、废弃，且仅无子任务时可直接完成；当前已完成仅无子任务时可撤销完成；历史未完成且没有活跃轨迹时可延续或废弃；历史已完成只可复制为新任务；未来待完成只可改期或回到任务池。
- 有子任务的任务行必须在列表内提供明确的展开 / 收起入口，展开后直接显示子任务完成态和难度权重；新增子任务仍只在详情页完成。

## 任务池页面

必须包含：

- 标题、说明、新建任务输入。
- 任务池任务列表。
- 任务池行首必须是 18px 灰色虚线空圆，占位语义为“尚未排期”，不得替换成彩色任务池图标。
- 任务池已经按分组标题组织，行内不得重复分组 badge；标题与最多两个完整标签同排，标签不足空间时必须以可点击 `+N` 收束，禁止把文字压成空色块。
- 任务池行内不得显示排期到今天、排期到明天、选日期或删除按钮；整行只承载任务身份与分类摘要，不创建第二条操作行。
- 右键任务行提供排期到今天、排期到明天、选日期和删除；该菜单与任务详情三点菜单复用同一动作定义、状态过滤和执行路径，不得维护两套操作清单。
- 空状态。

## 未来计划页面

必须包含：

- 按日期分组展示未来计划。
- 每个日期组可跳转到对应 Day Todo。
- 日期组标题中的“查看当天”链接必须紧跟日期标题，使用 10px 左右间距；不得使用 spacer 推到分组行最右侧。
- 未来计划任务可选中、右键、查看详情、改期、回到任务池、调整顺序。
- 未来计划任务的选中、右键和查看详情必须作为独立交互契约点保留。
- 未来计划任务的调整顺序必须同时映射到 `MacUIFuturePlanElement.priorityStepper` 和行内入口 `MacUIFuturePlanElement.taskRowMoveButtons`；两者描述同一个排序能力的语义控件与视觉入口。
- 空状态。

## 未完成池页面

必须包含：

- 按任务链去重展示未完成轨迹和已废弃但仍需可见的任务链。
- 每条展示未完成次数、延续次数、最近未完成日期。
- 未完成行元信息必须按当前契约使用纯文本与 `·` 分隔：未完成次数为 warn 色文本，延续次数和“最近未完成 · 日期”为 t3 文本；不得把未完成次数退化为胶囊 chip 或省略“最近未完成”标签。
- 未完成行的“明细”展开入口必须位于元信息行最右侧，和失败次数、延续次数、最近未完成日期同一行；不得放到标题行或操作按钮列。
- 若已有活跃日轨迹，行内显示“已延续到某日，当前待完成”，该状态本身就是当前轨迹的直接跳转入口。
- 若无活跃日轨迹，右键菜单提供延续到某日和废弃任务链。
- 若任务链已废弃，仍在未完成池展示，状态标记为“已废弃”，并在右键菜单提供“重新启用”；重新启用只取消废弃标记，不创建今日任务。
- 可展开明细，逐条显示未完成日期、序号、已延续到哪天。
- 打开详情时使用通用任务详情栏：标题为“任务详情”，包含未完成或已废弃状态、日期、延续上下文、历史只读提示、完成进度和任务轨迹；延续、废弃和重新启用由任务行右键菜单与详情三点菜单共享，详情正文不再放置重复操作区；已有活跃日轨迹时仍保留其状态跳转入口。
- 空状态。

## 已完成池页面

必须包含：

- 按完成日期分组。
- 父任务完成记录逐条展示。
- 子任务完成记录也要单独展示，并显示属于哪个父任务。
- 每条完成记录展示轨迹节点。
- 每条通过右键菜单支持跳转当天、复制为新任务，行内不显示这两个低频按钮。
- 父任务完成记录可在右上角显示完成时间；子任务完成记录右上角只显示“子任务”标签，不显示额外完成时间，保持当前信息密度。
- 父任务完成记录打开详情时使用通用任务详情栏：标题为“任务详情”，包含完成进度、描述、任务轨迹和轨迹下方附言；跳转当天和复制为新任务保留在右上角三点菜单，不额外显示统计卡、锁定提示、子任务快照或底部重复操作区。
- 空状态。

## 日历页面

必须包含：

- 月标题、上一月、今天、下一月。
- 周一开始的月份网格。
- 每日格子展示日期、今天标记、完成热度块、最多 6 条任务摘要和更多数量。
- 任务摘要使用状态色点，完成/废弃使用删除线。
- 右侧选中日详情：日期、星期、今日/历史/未来 badge、任务总数、打开 Day Todo。
- 右侧选中日详情必须补充当天状态分布、完成率、延续摘要、变更摘要和风险摘要；这些基础分析来自本地任务轨迹，不依赖烛龙 API。
- 右侧选中日任务列表和空状态。
- 右侧选中日任务行必须复用 Day Todo 的轨迹元信息语义：延续任务显示“第 N 次延续 · 持续 X 天”，变更任务显示变更提示，不得退化为只显示延续次数。
- 方向键日期切换：左 / 右切换前后一天，上 / 下切换前后一周；跨月时月视图跟随选中日期切换。

## 烛龙页面

- 首页必须同时保留自由意图输入和固定入口；输入框内部不得放置无行为的装饰性操作图标，文字与提交按钮必须在输入 surface 内垂直居中。
- 没有待处理会话时，PageHeader、输入框与固定 workflow 必须作为同一个稀疏内容组，在主页可用视口内垂直居中并保持同一条左对齐轴；出现待处理会话后，整个内容组恢复顶对齐和自然滚动。
- 输入框使用 `14pt` 普通圆角矩形，不得使用半高圆角把它做成胶囊。
- 自由输入下方使用唯一一张无外框单层列表，依次展示任务成形、每日收尾、排期与分类入口；不得再用分组标题、描边卡片、色块图标、胶囊徽章和尾箭头重复制造层级。点击入口必须直接建立对应的有界会话，不得只把示例文案填回输入框。
- 排期与分类保持较弱语义，并在标题旁以弱文本明确标记“建议模式”；在各自专属状态机与应用 diff 完成前，不得把它们描述为完整固定工作流。
- 首页使用单一视觉轴；没有待处理会话时必须完全折叠“待你决定”空区和右侧工作空间栏。进入会话后才恢复上下文栏；非空待决定会话继续位于入口区下方。

## 设置页面

必须包含：

- “组织”页的“分组与标签”摘要必须使用单层紧凑控制条：左侧说明组织语义，中部显示当前分组与标签数量，右侧提供明确管理入口；高度不得超过 120pt，不得用嵌套统计卡、装饰性预览和重复说明堆高页面。
- 分组与标签管理必须从任务详情或设置入口打开主窗口中央的 window-level modal，不得使用依附按钮的 popover；modal 必须提供明确关闭入口，并使用低对比浅色工具栏和线性列表：分组／标签切换显示数量，搜索与新建同排，使用中与已归档分段，已归档默认折叠；每项必须显示当前／历史引用数并保留重命名、归档／恢复和受引用保护的废弃操作。
- 分组与标签管理浮窗的新建编辑器必须在当前情境内展开；历史引用保护提示必须固定可见，操作错误另行显示，不得覆盖历史语义提示。
- 外观分段控件：冷灰、微暖纸感。
- 语言分段控件：中文、English。
- 数据区：导出数据 `JSON`、导入数据。
- 同步区：必须显示主数据模式选择（本地优先 / 在线优先），并说明两种主模式互斥，不得并行写入同一份任务事实。
- 本地优先模式下必须显示独立启用开关、同步端点、手动 / 自动触发、实际自动间隔和最近结果；最近结果必须包含等待、失败与未解决冲突，不能只显示笼统成功。
- 本机数据仍是事实源；iCloud Drive 与本地文件夹只保存逐条同步记录、仓库索引和 ref，不保存 SQLite 或数据包整包。
- 同步配置按设备保留；远端偏好只能更新主题和语言，不能开启同步、切换端点或改变数据模式。
- 在线优先的定时备份尚未接入时只显示规划中说明，不显示可操作的频率或目标假控件。
- 同步端点区：iCloud Drive 与本地同步文件夹显示运行时可用性；自定义服务、S3 和 WebDAV 显示规划中。
- 烛龙配置区：设置页必须包含“启用烛龙”开关和 Provider 配置表单；Provider 类型、Base URL、模型、API Key、保存、测试连接和清空都必须在设置页完成，不得放在烛龙页面内。
- 设置页必须使用平衡布局呈现偏好、数据、同步、烛龙配置和隐私边界，不得只占左侧窄列并在右侧留下大面积空白。

## 右侧详情栏

未选中任务时：

- Day Todo 页面显示每日复盘。
- 任务池、未来计划、未完成池、已完成池显示页面默认汇总 / 分析面板，不得留空，也不得只显示一句提示。
- 页面默认汇总 / 分析面板必须包含本地统计、本地算法信号、可执行建议，以及“开启烛龙后可获得更丰富分析”的轻量占位；这些基础分析不依赖烛龙 API 或 API key。
- 通用右侧详情栏的未选中提示只作为兜底 rail hint，不得用于任务池、未来计划、未完成池、已完成池的默认状态；也不得复用页面级大图标空状态。
- 日历和设置不显示通用详情栏。
- 日历页面不显示通用任务详情栏，但必须显示自己的选中日详情面板；设置页面不显示右侧详情栏。

选中任务时必须包含：

- 详情标题、关闭按钮、任务标题、三点菜单。
- 详情标题和任务标题必须分别实现，不能合并为一个视觉元素。
- 三点菜单必须是 22px 纯图标触发器，不得显示文字省略号或原生下拉箭头。
- 三点菜单与对应任务行右键菜单共享动作定义；任务池的排期／删除、未完成池的延续／废弃／重新启用、已完成池的历史日期跳转／复制均只保留这一份菜单动作，不在详情正文追加排期或计划操作区。未完成任务已有活跃轨迹时，其状态文字仍可直接跳转当前轨迹。
- 状态 chip、所属日期或任务池位置。
- 轨迹上下文卡片：以单行紧凑展示延续次数、持续天数、变更、回池等，不得退回多行统计卡。
- 历史只读提示。
- 完成进度区。
- 可编辑的“分组与标签”使用无内层卡片的紧凑两行编辑器：当前分组值本身就是 picker，点击当前值（无分组时点击“选择分组”占位）直接打开分组菜单，不得再显示独立“选择”或“更换”按钮；管理入口保留为不同操作。标签以可换行 chip 展示；标签输入只在用户点击“添加”后展开，不得常驻占用详情栏高度。
- 描述编辑器必须紧跟任务标题显示，位于任务状态、上下文卡和完成进度之前；标题与描述之间固定 `6pt`，标题编辑高度为 `22–72pt`，描述编辑高度为 `32–132pt`，二者文本 inset 均为 `3pt`；不得显示“描述”小标题或常驻背景、描边、圆角文本框 surface。只有系统原生焦点与选区反馈可以暂时提示编辑状态。
- 描述使用标准多行 Markdown 编辑路径，保留原生选区、全选、剪切、复制、粘贴、撤销和重做，并支持粗体、斜体、行内代码、链接、缩进和硬换行；不得用脱离 responder chain 的自绘输入替代 `NSTextView` 原生编辑语义。
- 附言区。
- 附言区必须位于任务轨迹下方；附言按带时间戳的独立条目排列，不得退回整块可覆盖文本区；新增附言使用单行 composer，避免光标和文字基线错位。
- 附言区只使用一个浅暖灰容器，不为每条附言新增卡片、徽章或装饰图标。每条附言的操作行只显示 10.5px 时间戳和右侧 18×18 低对比省略号菜单；菜单承载编辑与删除两个真实操作。
- 编辑附言必须在原条目内展开；保存和取消只在编辑态出现，退出编辑态后立即收起，不新增弹窗或第二层容器。
- 子任务区。
- 任务轨迹时间线；详情栏章节标题显示为“任务轨迹”。
- 通用任务详情必须在任务轨迹标题行或紧邻的上下文卡中显示链条摘要；已有上下文卡时不得在同一详情栏重复显示同一组摘要。已完成详情的任务轨迹标题行必须显示持续天数和终态 chip。
- 任务轨迹的当前节点必须有 accent-soft 选中背景，并使用细边框“当前所在”badge；不能只依赖填充式“当前”文字 chip。

## 进度规则

- 无子任务的任务可使用手动完成进度。
- 手动完成进度滑杆必须使用确定性自绘轨道、蓝色已完成填充、可见 thumb 和 5% 步进刻度；不得依赖 macOS 系统 Slider 的默认灰色渲染。
- 手动完成进度滑杆必须暴露可访问调节入口，递增/递减按 5% 步进并遵守进度下限。
- 详情栏完成进度区域不显示“手动完成进度”或“按子任务自动计算”模式胶囊；模式信息只保留在控件语义和可访问说明中。
- 只读完成进度标题和百分比必须在同一行，轨道位于下一行；可编辑手动滑杆保留已验证的标题、百分比和滑杆垂直节奏。
- 有子任务的任务进度必须按子任务自动计算。
- 子任务有难度权重：简/中/难，对应 English `S/M/L`。
- 延续后的任务进度不能低于历史已达进度，UI 显示下限。
- 进度达到 100% 后 UI 可以驱动完成态，但落库仍必须经过领域接口。
- 历史日进度只读。

## 描述与附言

- 任务详情必须包含描述和附言；描述紧跟任务标题显示，不使用小标题；附言仍作为独立区块显示在轨迹下方。
- 描述用于背景、目标或范围。
- 描述的 Markdown 编辑必须遵循 macOS 原生命令：`Cmd/Ctrl+A` 全选，`Cmd+X/C/V` 剪切／复制／粘贴，`Cmd+Z`／`Shift+Cmd+Z` 撤销／重做；Markdown 快捷键支持粗体、斜体、行内代码、链接、Tab 缩进与 `Shift+Return` 硬换行。
- 附言用于临时想法、提醒或补充说明，视觉上是浅暖色、斜体，并按时间戳条目排列。
- 当前日、未来计划和任务池允许新增、编辑和删除附言条目。
- 历史日只读。
- 描述和附言操作都不能改写历史日轨迹。

## 子任务规则

- 子任务可完成、显示完成日期、显示锁定图标。
- 历史已完成子任务不可在后续日期改写。
- 子任务权重可在当前日编辑。
- 延续时只延续未完成子任务，已完成子任务留在历史轨迹中。
- 任务轨迹时间线必须显示当日完成的子任务和被延续的子任务。

## 每日复盘

- 每日复盘包含统计卡、状态分段条、状态图例、今日总结、未完成原因、明日注意事项。
- 当前日每日复盘区必须包含“让烛龙分析今日”入口，进入每日收尾会话后分别审查复盘文本与 Todo 处置。
- 历史日复盘可补写。
- 未来日不显示复盘编辑，只显示未来日无复盘提示。
- 输入后显示自动保存反馈。

## 操作与弹窗

任务动作必须覆盖：

- 标记完成、撤销完成。
- 延续到某日。
- 变更为新任务。
- 回到任务池并留下轨迹。
- 废弃任务链。
- 重新启用已废弃任务链。
- 改期。
- 复制为新任务。
- 排期到今天、明天或指定日期。
- 删除尚未排期的任务；仅通过任务池行右键菜单与共享详情三点菜单触发。

弹窗必须覆盖：

- 延续/排期/改期/跳转日期/从任务池排期的日期选择器。
- 变更任务弹窗：旧任务删除线展示，新任务标题输入，确认变更。
- 变更任务弹窗内的旧任务删除线预览、新任务标题输入和确认按钮必须作为独立契约点保留。
- 右键菜单。
- toast。

## 变更任务语义

- 旧任务必须保留在当天并标注已变更。
- 新任务必须以待完成出现在同一天。
- 新任务开启新的任务链，而不是继承旧任务链。
- 旧日轨迹通过变更指针关联到新日轨迹，用于 UI 展示“被变更为：目标任务标题”并支持跳转到目标日轨迹。

## 撤销

- `Cmd+Z` 只允许撤销当前日与未来计划的误操作。
- 不能撤销历史事实。
- 任务池新增、复制为新任务、当前日延续、当前日废弃、未来改期、当前日任务事实编辑都必须进入有限撤销栈；历史日废弃、历史日延续等改写历史状态的动作不得进入撤销栈。
- 无可撤销操作时显示提示。
- 无可撤销操作时的提示必须作为独立 toast 契约点保留。

## 后端硬需求

当前 UI 要求后端必须支持：

- 任务描述和附言，且历史日不可被覆盖式改写。
- 手动完成进度。
- 子任务难度权重。
- 按子任务权重自动计算进度。
- 进度下限，防止延续任务进度回退。
- 已完成池中展示子任务完成记录。
- 日历月视图需要按日统计任务和完成热度。
- 设置中提供主题、语言、事务性导入导出、同步端点和显式启用的 iCloud Drive 记录同步。
- 任务池持久化视图必须包含已经 **回池** 的任务链。
- 设置偏好必须支持冷灰/微暖纸感、中文/English。
- 有限撤销能力必须支持 `Cmd+Z` 当前日与未来计划误操作，历史事实不可撤销。
- 变更任务必须保存旧日轨迹指向新日轨迹的变更指针。
