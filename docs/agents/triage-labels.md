# Triage labels

Engineering skills 使用五种 canonical triage roles。本文件把这些角色映射到仓库 issue tracker 中的实际 label 名称。

| Canonical role | Tracker label | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待 maintainer 评估 |
| `needs-info` | `needs-info` | 等待 reporter 补充资料 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，agent 无需额外人工上下文即可处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实施 |
| `wontfix` | `wontfix` | 不会处理 |

当 skill 提及某个 triage role，例如“应用 AFK-ready label”，必须使用表格中对应的 tracker label。

若 GitHub 上的实际 label vocabulary 日后改变，应更新第二栏，避免创建重复标签。
