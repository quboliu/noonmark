# 烛龙 AI 采用旁路 Agent 与 provider 中立架构

晷迹支持 **烛龙 AI** 作为可选 Agent，但它不能成为普通清单功能的依赖。Day Todo、任务池、未来计划、未完成池、已完成池、每日复盘和数据包导入导出必须在没有 AI provider、没有网络或 provider 故障时完整可用。

**Consequences**

- 烛龙 AI 只能读取用户授权范围内的任务轨迹，并生成建议草稿。
- 烛龙 AI 不直接写入历史事实；创建任务、拆子任务、排期、延续、废弃、label 修改和复盘文本保存都必须经用户确认后走普通领域接口。
- provider 层保持中立，第一版必须支持自定义 provider，未来可以增加原生云 AI provider，但不能移除自定义 provider。
- API Key 进入 Keychain 或等价安全存储，不进入普通配置文件、日志、数据包或崩溃报告。
- 烛龙 AI 的习惯画像只作为时间窗口内的证据化假设，不作为永久用户身份。
- 《苦昼短》和衔烛龙意象属于烛龙 AI 的品牌与设计素材，不改变任务状态机和日轨迹规则。
