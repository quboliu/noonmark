# 可行性审查使用版本化世界约束库

个人历史无法覆盖所有新任务，LLM 训练记忆又不足以构成科学证据。晷迹因此把稳定物理或逻辑约束、带版本的对象事实、本地测量和有一手来源的保守能力边界建模为 **可验证世界约束**，保存在白盒、版本化的 **世界约束库** 中，供可行性审查构造可复核证明链。

**Consequences**

- 每条约束必须声明来源、适用对象和版本、单位、不确定性、更新时间及计算规则。
- 对随版本变化的对象优先使用本地测量，不能把某次规模数字永久写死。
- LLM 可以发现候选约束、检索和解释现有条目，但不能自行写入或升级硬知识。
- 模型训练知识未进入约束库前仍只能作为显式假设。
- 规划与事件记录必须绑定所用约束版本，后续更新不能改写旧结论。
- 第一阶段只覆盖稳定通用约束、用户约束和本地可验证事实，不维护通用知识百科；随版本变化的领域知识按需要另行审查引入。
