## 用户可见变化

- 收敛飞光右栏：移除重复正文和无独立价值的大型编辑入口；没有独立信息时保持留白。飞光页输入框改为默认完整展开，不再提供收起状态。
- 子任务难度入口改为复选框右侧的紧凑深浅圆点，保留原生菜单、键盘与 VoiceOver 语义；标题到删除按钮的间距缩至 `4 pt`，把横向空间还给正文。底层难度模型与持久化格式不变。
- Sticky Note slogan 改为「把值得反复看见的内容，留在手边。」；「飞光」只表示模块入口或内容来源，单条内容统一使用「记录／条目」与 `entry`。

## 资料兼容

- SQLite：当前 schema v17；继续支持受控 v15 原地升级至 v17。本版没有 schema、同步记录或领域资料格式变更。
- JSON：严格 canonical v6 数据包继续可导入；当前导出格式仍为 v7。
- 未知 schema、未知 format 与非 canonical 输入维持 fail-closed；本版不新增兼容层、迁移路径或回退机制。
