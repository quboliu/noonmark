# 以前向计划修订管理重复任务

重复任务的标题、分类和计划规则必须可修改，但完成、未完成、延期和既有计划日都是历史事实，不能随着父任务设置变化而被覆盖。晷迹把重复任务建模为拥有可编辑模板的父任务，把每个计划日继续建模为独立实例，并以追加式重复计划修订从生效日起重排未来；已开始的系列从明天生效，尚未开始且没有历史事实时才允许调整开始日期。

按达成次数结束会在未达成时产生无界义务，因此该条件必须同时具有最长运行日期，并只在完成日锁定后判定达标。所有系列维持有限日期范围；规则修改只取消或新增尚未形成历史的实例，旧实例身份、分类快照和取消原因继续保留。这个取舍牺牲了任意回溯编辑和无限重复，换取可验证的历史一致性、有限存储和确定性同步。
