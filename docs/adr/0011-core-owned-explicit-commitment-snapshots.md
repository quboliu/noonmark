# 承诺快照属于本地核心并由用户明确授权形成

晷迹把 **确认今日计划**、**自动确认授权** 和不可覆盖、可版本化的 **承诺快照** 作为本地核心 Todo 能力，而不是烛龙或 Provider 状态。只有用户手动确认或命中其明确配置的自动确认规则时才形成承诺 ground truth；Day Todo 的自动到期任务、日内最终内容或系统午夜状态不能被追认为用户承诺。

**Consequences**

- 没有网络、Provider 或烛龙时，用户仍可确认今日计划并查看 **承诺兑现** 与 **实际产出**。
- `NoonmarkCore` 与 Storage 持有承诺版本和确定性结算；`NoonmarkAI` 只读取、解释并提出建议。
- 普通快速捕获不创建承诺；日内新增任务不能反向改写原版本。
- 用户重新确认计划时只能追加新版本，不能覆盖旧版本。
- 自动确认默认关闭，必须记录触发规则和来源；手动与自动承诺快照分别校准。
- 用户界面以“确认今日计划”引导动作；“承诺快照”主要出现在历史、解释和审计层。
