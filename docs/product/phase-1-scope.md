# 一期功能范围

本文记录晷迹（Noonmark）第一期 Mac 端产品范围。第一期目标是验证“每日任务轨迹不可删除、跨日只能延续复制、每日复盘可回看”的核心理念，而不是复刻 Todo清单的全部外围能力。

## 包含范围

- **Day Todo 日视图**：展示某个自然日的任务轨迹。
- **日期快速切换和历史回看**：用户可以方便切换日期，回顾每天写了哪些任务、完成了哪些、未完成哪些、延续了哪些。
- **未来日期排期**：用户可以切换到未来日期提前安排任务和调整当日优先级，但不能提前完成或生成复盘结算。
- **任务池**：管理尚未排期到具体日期的任务。
- **未来计划**：跨日期汇总所有已排期到未来日期但尚未到期的计划草稿。
- **已完成池**：按完成日轨迹逐条汇总已完成任务，并展示每条任务从哪天开始、延续到哪些日期、在哪天完成。
- **未完成池**：按任务链去重汇总存在未完成日轨迹的任务，并展示未完成明细。
- **排期**：将任务池任务安排到某个 Day Todo。
- **完成与当天撤销完成**：当前日期内允许在待完成和已完成之间切换。
- **日结束自动结算**：按本地 00:00 将前一日待完成任务结算为未完成。
- **延续复制**：从历史未完成轨迹或未完成池复制到目标日期，并记录延续次数。
- **变更**：旧任务标注为已变更，并自动生成同日新任务，新任务开启新的任务链。
- **回池**：将已有轨迹的任务放回任务池，同时保留原日轨迹。
- **废弃**：终止任务链未来继续出现，但保留所有历史日轨迹。
- **复制为新任务**：从历史任务或已完成任务创建新的独立任务，不继承原任务链。
- **子任务**：作为日轨迹内的任务细化项，不独立形成任务链；跨日延续时保留子任务轨迹线。
- **当日优先级**：任务进入 Day Todo 时形成稳定执行顺序事实；当前浏览通过置顶队列和查看排序控制，日结束后顺序事实不可改。
- **查看排序**：按创建时间、首字母等临时浏览顺序查看，不改写当日优先级。
- **每日复盘**：包含自动统计和用户手写总结。
- **本地持久化**：SwiftUI + Swift 领域层 + SQLite/GRDB。
- **手动导出 / 导入数据包**：提供 canonical JSON 恢复包；导出写后回读并生成 SHA-256 回执，导入先完整校验并事务性写库，同时重置外来同步启用状态。
- **数据模式**：设置中提供本地优先 / 在线优先模式选择；两种主数据模式互斥，同一时刻只运行其中一种。
- **iCloud Drive 记录同步**：本地优先模式可显式启用手动或自动记录同步；默认关闭，本机 SQLite 保持事实源，系统上传允许短暂延迟。
- **CloudKit adapter 门禁**：private database + `CKSyncEngine` adapter 已实现，但只有真实签名、授权 container 与显式启动参数齐备时才能启用；未通过 live 与双设备验收前不替换默认 iCloud Drive transport。
- **同步配置本地性**：跨设备偏好只交换主题和语言；数据模式、同步开关、端点与间隔不进入远端 payload。
- **同步端点入口**：本地文件夹可用；S3、WebDAV 与自定义服务继续显示为规划中；CloudKit 不作为普通开发包的可用入口。
- **定时备份策略占位**：在线优先的定时导出尚未接入；当前只提供手动数据包，不展示可操作的假控件。
- **烛龙 sidecar**：提供可选 AI 入口、自定义 provider 配置、复盘分析、任务拆解、排期建议和分组与标签整理；未配置 AI 时普通清单功能完整可用。
- **《苦昼短》/ 衔烛龙意象**：在烛龙 或关于页面中作为完整 slogan 元素使用。
- **单主窗口**：第一期只提供一个主窗口，在窗口内完成 Day Todo、任务池、已完成池、未完成池和复盘操作。

## 不包含范围

- 番茄钟
- 白噪音
- 图片附件
- 语音输入
- 自然语言日期解析
- 小组件
- Watch
- 账号系统
- CloudKit / `CKSyncEngine` 生产同步链路与物理双设备发布验收
- 周报 / 热力图 / 高级统计
- 多人协作
- 重复任务
- 多窗口编辑
- 菜单栏快速添加

## AI 边界

- Provider 产物只进入当前烛龙会话，不能直接写入任务事实。
- AI 规划、Todo 变更 diff 与复盘文本必须绑定当前会话和证据版本；用户明确确认后，才通过普通领域接口原子应用。
- AI provider 未配置、不可用或被关闭时，Day Todo、任务池、未来计划、未完成池、已完成池、每日复盘和数据包功能不得降级。

## 技术边界

- SwiftUI 是第一期不可变技术约束。
- 第一阶段不采用完整 event sourcing。
- 事实模型采用不可覆盖关系表，由领域层和数据库约束共同保证轨迹不可删除、任务定义不可覆盖、多活跃轨迹不可出现。
- 第一阶段数据包优先采用平台无关状态快照；同步协议不在一期定死。
