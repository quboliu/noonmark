## 需求与验收

按当前原生源码、代码化 UI 契约及真实 App 截图还原已有 Web 能力。不是重新设计一套待办网站。设置、工作区栏位、日期导航、任务详情、飞光编辑和 Sticky Note 必须按各自原生交互组织。不能把未实现的分类、重复计划、烛龙或原生数据包绘制成假入口，也不能恢复用户已经取消的本地优先模式。

先用 `1200×768` CSS px 对照，再验 `1440×1000` 长页和 `390×844` 移动页面。尚无用户确认的 Web 像素 reference；本轮测量结构、尺寸、交互及真实运行截图，不宣称跨平台像素完全一致。Linux 无法执行原生 App，已提交原生截图过期部分须以当前源码校正。

## 像素级实施 prompt

### 共享工作区

使用当前 `MacUIShellLayout`：左导航宽 220px，紧凑态 72px；详情右栏 280px；页面水平 inset 20px，右栏 inset 14px；导航行高 34px、文字 14.5px、图标 14px；栏位开关 28px。主区不加 1040px 居中上限、不保留大品牌区和 NOONMARK 眉题。页标题一般 21px，Day Todo 日期标题 20px/600。主区和右栏分别滚动；长页滚动不移走导航或右栏控制。桌面详情为非模态 rail，选中任务自动展开；取消选择回到当前页面统计或复盘。移动用可关闭 sheet 与导航抽屉，焦点进入并在关闭后返回，隐藏控件不可继续 Tab。

默认冷灰：原生 `Theme.swift` 的 background `rgb(253,253,253)`、sidebar `rgb(250,250,249)`、line `rgb(230,230,233)`、text1 `rgb(28,28,31)`、text2 `rgb(107,107,117)`，主强调色蓝。微暖纸感使用原生 warmPaper 色族，仍保持亮色。导航选中使用浅蓝、语义图标颜色、无独立色块容器。状态靠控件与元信息表达，不给每行重复“待完成”文本。

### Day Todo、任务与日历

日期主标题右侧放视图排序、前后日、选日期；下面 14 个等宽日期单元，星期/日号/任务点分层，选中圆底与今天标识分开，方向键可逐日选择。日期不能用裸 date input 冒充 strip。今天及未来日提供行内新增，Enter 在 IME composition 时不得提交，保存后留在输入位；旁边的“从任务池排期”必须真正调用 ScheduleTask。

任务行上/下 padding 8px，圆形完成控件命中区 28px，标题 13px/500，按真实子任务显示折叠入口与进度，不强迫所有行显示描述。右键/更多菜单集中低频动作，选中标题打开右栏；详情标题和描述在上下文内编辑。保留完成/撤销、排期/延期/延续/回池、子任务、进度、废弃及完整历史，不得因换容器损失现有命令路径。

未来计划按日期分段并可“查看当天”；已完成和未完成使用实际历史派生次数、日期与子项折叠。日历使用真实 snapshot 的月份格及日期摘要，点击日期查看该日，不复制领域事实。复盘位于 Day Todo 右栏，完成率、近 7 日小图和数量均来自真实 traces，三项正文继续使用 UpdateReview 与现有草稿机制。

### 设置

设置为独立模态工作面，桌面内容 860×660px，左分类栏 230px，右内容 horizontal padding 34px、vertical padding 30px、标题 20px；过小 viewport 时自适应而不横向溢出。切换 pane 不丢工作区选中日期、任务、滚动位置；Escape/关闭恢复原触发控件。分类采用原生图标+文字，选中中性灰底，分段控件 max-width 320px、高 24px。

偏好使用真实冷灰/微暖纸感切换、页面滑动方向、应用内快捷键开关、可展开的诗编辑/显示/恢复默认；本机偏好按实例与 owner 隔离保存。浏览器不冒充系统全局快捷键，明确标为应用内。数据 pane 复用当前真实加密备份下载；连接 pane 呈现当前实例与会话；隐私 pane 呈现真实数据/草稿/凭证边界。原生语言切换、组织和烛龙尚缺完整 Web 实现，不能放置假切换或假保存按钮；仍列为待完成能力，不能宣称设置功能对等。

### 飞光与 Sticky Note

飞光沿用共享外壳，当前源码不再在右栏重复正文。composer 默认完整展开，最小 112px、圆角 12px、水平 inset 16px、顶部 13px、动作区 42px、主动作 32px；Cmd/Ctrl+Enter 保存，Enter 换行。时间线 max-width 760px，按实例时区自然日分组；正文在前，时间及精选元信息在后，条目 inset 12px/10px、元信息间距 6px、段间距 18px。双击在原位置编辑，保存/取消/错误不跳 modal；保留 IME 和草稿恢复。Sticky Note 使用原产品名称，只有一个流/墙切换下拉，墙与流复用同一份飞光事实；编辑通过“打开来源”回飞光原位置，不创建正文副本。
