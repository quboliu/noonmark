# 烛龙极简首页历史设计记录

> 归档设计材料。它不再是当前产品、测试 fixture 或视觉回归 oracle；当前验收只使用真实 `.app`、`NoonmarkMacUIContract` 与用户确认的真实 App reference。

## 要回答的问题

用户进入烛龙首页后，能否立即知道：可以做什么、哪些事情正在等待自己、下一步是什么？

## 共同产品边界

- 首页保留一个自然语言主入口，并在其下方用单层列表展示任务成形、每日收尾两个固定工作流；排期与分类作为较弱层级的专项助手，不使用一排“生成”按钮或 Dashboard 卡片。
- 固定入口以用户结果命名，并直接建立对应的有界会话，不再只把示例文案填回输入框。
- 首页不展示 Provider 配置、权限 profile、默认可见范围、YOLO、记忆管理或系统边界说明；这些属于设置。
- 实际使用范围、记忆和远程 Provider 只在动作即将使用时按情境披露。
- 删除“草稿收件箱”。只有确实等待用户动作或可以恢复的会话出现在首页；草稿、简报与 diff 留在所属会话流中。
- 每个等待项都必须同时说明“现在是什么状态”和“用户下一步做什么”，禁止只写“继续”“生成”“打开”。
- 烛龙事件历史保留轻量入口，但不与主动作争抢层级。

## 像素级 prompt

- 唯一外框来自当前 Noonmark Mac App：`1320 × 820` 逻辑窗口、`240px` sidebar、冷灰亮色主题、系统字体。不得复刻 ChatGPT 品牌、网页 toolbar 或 Scheduled 业务语义。
- 窗口背景 `#FDFDFC`，sidebar `#FAFAF9`，panel `#FFFFFF`，次 panel `#FBFBFC`；普通线 `#E6E6E9`，强调线 `#CCCCD5`。
- 正文 `#1C1C1F`，次文 `#6B6B75`，弱文 `#A1A1AB`；主交互 `#2961C7`，soft accent `#EDF4FF`。`#7C5CFF` 仅用于烛龙导航图标及极淡标记。
- PageHeader 水平 `24px`、垂直 `16px`；标题 `21px/700`，副标题 `12px`。正文区域 padding `24px 24px 40px`，最大阅读宽度固定为 `780px`，空首页在主区域内居中，不显示右侧工作空间栏。
- 主输入是页面唯一大视觉重心：高 `58px`、圆角 `29px`、`1px #E6E6E9` 边界和不超过 `16px` 半径的极淡阴影；聚焦时只改变边界颜色。输入文本 `13px`，placeholder `#A1A1AB`。右侧只保留一个有真实提交行为的 `34px` 圆形按钮，不增加 `+`、麦克风或装饰图标。
- 输入与工作流清单间距 `24px`。四个入口合并为唯一一张无外框清单；每行高 `68px`，左侧 `24px` 描边圆形启动符，标题 `13px/600`，说明 `11.5px`，行间只留一条从正文起点开始的 `1px` 分隔线。不得使用卡片外框、色块图标底、尾箭头或第二组标题。
- 任务成形、每日收尾、排期、分类保持同一扫描轴。后两项用标题旁的弱文本“建议模式”表达产品边界，不使用胶囊 badge；它们仍直接进入各自有界会话。
- 没有待用户处理的会话时完全隐藏“待你决定”区域，不显示 `0 项`、分隔线或解释性空状态；有内容时才在工作流清单下方出现一组稀疏行。
- 页面允许的主要视觉单位只有 PageHeader、胶囊输入、单层工作流清单，以及非空时的待决定清单。禁止 dashboard card grid、统计 tile、常驻右侧“系统边界”、权限 chip、多组重复标题和为了装饰而存在的图标。
- 参考图只借鉴“标题 → 一句话解释 → 单一输入 → 稀疏列表”的层级、留白和可扫描性；不复刻 ChatGPT 的品牌、语音能力或 Scheduled 业务。

## 确认结构

首页固定为单列指令台：PageHeader 下方依次只有胶囊输入和四项平面工作流清单。只有存在待处理会话时，才在下方追加“待你决定”清单；空首页不显示右栏。不存在 A/B/C 方案切换或兼容渲染路径。
