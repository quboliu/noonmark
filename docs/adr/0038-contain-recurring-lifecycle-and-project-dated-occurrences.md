# ADR 0038：封闭重复计划生命周期并只投影日期实例

## 状态

已接受，部分取代 ADR 0034。

## 情境

ADR 0034 先把同一条重复轨迹作为父计划管理行投影到任务池、未来计划、未完成池和已完成池。实际体验中，同一个父计划在多个一级模块重复出现，既不能代表一个具体可执行日期，也让用户难以判断每个页面的职责。重复实例回池还会让原本由重复规则管理的义务脱离日期，破坏“父计划统一管理、日实例按日期执行”的边界。

用户确认重复计划应成为封闭生命周期模块：父计划、全部历史结果和纵向完成情况只由“重复计划”管理；外部页面只有 Day Todo 和未来计划可以展示某一天的具体实例。

## 决策

1. **重复任务** 父项只在“重复计划”出现。任务池、未来计划、未完成池和已完成池不得显示父计划管理行或固定“重复任务”区；日历不得显示父项或重复实例。
2. Day Todo 按所选日期显示重复实例，并保留该日已经形成的完成、未完成、延期、变更或废弃结果。这是日级事实，不等于进入通用状态池。
3. 未来计划把待执行重复实例作为普通日期行展示，不显示父计划总行。重复实例使用 `repeat` 前导符号，并继续显示自己的分类、标签和详情入口。
4. 未来计划提供 7 天、15 天和 30 天三档 **重复实例可见范围**，默认 15 天。范围从明日起按自然日计算，只裁剪重复实例；普通未来任务、重复规则、结束条件、完整轨迹和直接打开某个未来 Day Todo 都不受影响。该偏好属于设备侧视图状态，不进入任务领域、同步或导出包。
5. 任务池、未完成池和已完成池在 Core 查询层排除带 `TaskCycleMembership` 的任务链，侧栏数量直接使用同一投影，不能只在 SwiftUI 行层隐藏。
6. 重复实例不能回池，也不能使用普通“删除今日临时任务”语义。Core 的 `returnToPool` 与 `deleteNewCurrentDayTask` 对重复成员 fail-closed，单项菜单和批量动作也不提供这些入口；改期、延期、完成、变更、废弃、跳过本次和停止重复继续按既有规则工作。
7. 既有普通任务仍可单向转为重复任务；转换提交后，原任务链成为首个重复实例并立即离开任务池及通用状态池，不保留持续关联。
8. “重复计划”继续按父项计数并保留完整重复轨迹；完成、未完成和未来目标仍从真实日轨迹派生，不增加第二套状态事实。
9. 全局搜索只为每个重复任务建立一个父项结果，并跳转到“重复计划”详情；不得为每个日实例建立重复搜索结果，也不得把完成实例路由到通用已完成池。

## 影响

- 优点：一级模块职责稳定。任务池只表示未排期普通任务，未来计划只表示具体未来日期，通用完成／未完成池只表示普通任务，重复计划独占系列纵向历史。
- 优点：用户调整可见范围时只是改变查询窗口，不会产生、删除或改写任何任务事实。
- 优点：Core、侧栏数量、批量动作和 SwiftUI 使用同一隔离边界，避免“列表隐藏了但统计仍泄漏”的漂移。
- 代价：用户不能把某一次重复实例改造成无日期的任务池事项；需要继续处理时应改期、延期，或把内容另建为普通任务。

## 风险与回滚

- 风险：未来计划默认窗口可能让较远的重复实例暂时不可见。页面必须持续显示当前 7／15／30 天选择，重复计划完整轨迹仍可查看全部日期。
- 风险：日历、搜索、通用统计或 AI scope 若绕过公开集合查询，可能再次计入重复实例。演示与测试必须同时检查列表、侧栏数量和 Core 查询。
- 项目尚未发布并执行开发数据 clean cut，不迁移旧回池重复实例。回滚只能回到前一提交并执行 `scripts/reset-dev-data`，不得让旧二进制读取新开发数据。

## 验证

- `TaskCycleSeriesTests` 覆盖 7／15／30 天窗口、普通远期任务不受裁剪、三类通用池与日历零泄漏、日级结果仍可从 Day Todo 与完整轨迹读取，以及重复实例回池和普通今日草稿删除的原子拒绝。
- `WorkspaceSearchIndexTests` 覆盖一个重复任务只产生一个父项结果，标题和说明查询都回到“重复计划”，日实例不进入索引；原生命令真实 App E2E 通过独立 Search window 输入父项标题、回车跳转重复计划详情，并在重启后复验同一持久化身份。
- `RecurringFuturePlanVisibilityTests` 覆盖默认值、持久化和非法值回落。
- 交互演示固定同时包含窗口内与窗口外的未来重复实例；真实 App 检查 Day Todo 与未来计划的具体实例、重复前导符号、15 天默认入口，以及任务池、未完成、已完成和日历没有重复父计划管理行或日实例。
- 真实 UI mutation E2E 与 SQLite 重启探针验证转换、跳过、停止、规则编辑和隔离实例持久化，且不再创建回池重复实例。
