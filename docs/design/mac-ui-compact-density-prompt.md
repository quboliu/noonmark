# Mac UI 紧凑密度像素级实现 Prompt

## 参照与目标

以用户于 2026-07-13 提供的 TickTick / 滴答清单并排截图为视觉参照，并以同一台机器的真实窗口边界作为尺寸证据：TickTick 当前窗口为 `1000 × 768pt`，晷迹当前窗口为 `1320 × 820pt`。截图中 TickTick traffic light 的可见直径为 `12pt`，晷迹为 `14pt`。

本轮只调整视觉密度，不改变页面信息架构、功能、领域语义、数据和交互能力。结果应像同一个产品整体缩小一档，而不是局部字体突然变小、留白仍然松散或点击区域跟着缩小。

## 唯一当前尺寸

- 主窗口默认启动尺寸必须是 `1000 × 768pt`。
- 主窗口最小尺寸必须是 `960 × 720pt`。
- 左侧 Sidebar 宽度必须是 `220pt`。
- 通用右侧 Detail Rail 宽度必须是 `280pt`。
- 日历内部分析 rail 宽度必须是 `248pt`。
- 页面主要水平 padding 从 `24pt` 收紧为 `20pt`；列表行主要纵向 padding 从 `9–10pt` 收紧为 `7–8pt`。
- 不设置虚假的最大内容尺寸；窗口继续支持系统缩放、关闭后保留进程及 Dock 重新打开。

## Traffic lights 与品牌区

- 三个 traffic light 可见圆点直径统一为 `12pt`。
- 每个按钮保留 `20 × 20pt` 的透明点击区，三个按钮中心距为 `20pt`；不得因视觉缩小而降低可操作性。
- Sidebar 顶部 padding 为 `10pt`，横向起点维持约 `16pt`，避免按钮贴边。
- Clock Logo 从 `24pt` 缩为 `22pt`，品牌字从 `17pt` 缩为约 `15.5pt`。
- 导航 icon 视觉字号从 `15.5pt` 缩为 `14pt`，占位宽度从 `21pt` 缩为 `19pt`。
- 导航主文字从 `14.5pt` 缩为 `13.5pt`，导航行高从 `36pt` 缩为 `34pt`。

## 字体与图标密度

- 所有 SwiftUI 显式系统字体、继承字体、SF Symbols、AppKit `NSFont` 编辑态和原生附言操作控件必须使用同一个紧凑尺度源。
- 基础字号大于或等于 `10.5pt` 时乘以 `0.92`，再四舍五入到最近的 `0.5pt`；低于 `10.5pt` 的微型字不再缩小。
- 关键结果应为：`21→19.5`、`17→15.5`、`15.5→14.5`、`14.5→13.5`、`14→13`、`13→12`、`12.5→11.5`、`12→11`、`11→10`、`10.5→9.5`；`10pt` 及以下保持原值。
- Songti SC 诗文、Markdown 编辑态与 Markdown 展示态必须经过同一映射，不能在进入编辑时突然变大。
- 禁止使用根视图 `scaleEffect`、渲染后缩放或模糊变换；布局尺寸、字体和图标必须由 token 驱动。

## 关键页面密度

- Day Todo 页面标题约 `19.5pt`；14 日 Date Strip 在 `500pt` 主内容宽度内完整展示，不得横向滚动或丢失日期。
- 任务行标题约 `12pt`，正文约 `11–11.5pt`，元数据约 `10pt`；状态与操作的透明点击区不得随 glyph 缩小。
- 默认 `1000×768pt` 窗口下，任务池主内容约 `500pt` 宽。任务池行不得把标题、分组／标签和“排期到今天／明天／选日期／删除”四组操作硬塞进同一横行：首行承载 `18pt` 未排期 glyph、完整可读标题和分类摘要，次行右对齐保留三项完整文案操作与删除；窗口足够宽时才允许收回单行。
- 任务池已经按分组显示线性分组标题，行内不得再次用分组 badge 重复同一信息；行内只显示标签。其他任务列表仍显示一个分组和最多两个标签。
- 分组与标签 badge 必须保持自身文字的 intrinsic width，禁止压成只剩图标或空色块。横向空间不足时依次显示 `2 → 1 → 0` 个标签，并把所有未展示标签合并为可点击的 `+N`；popover 必须仍列出全部标签，不能丢数据、换成不可操作省略号或增加一排装饰容器。
- Detail Rail 内边距从 `16pt` 收紧至 `14pt`，区块间距从约 `14pt` 收紧至 `12pt`。
- 烛龙 composer 高度从 `58pt` 收紧至 `54pt`，固定 workflow 行高从 `68pt` 收紧至 `62pt`，继续保持单一视觉轴与扁平列表。
- 分类管理浮窗、设置页、日历、未来计划、未完成池、已完成池在新窗口宽度下不得裁切操作、隐藏信息或出现水平溢出。

## 禁止项

- 不得保留 `1320 × 820`、`1180 × 760` 或 `defaultLaunch1320x820` 的兼容别名与双路径。
- 不得通过删减 Detail Rail、隐藏按钮、截断英文文案或减少 14 日 Date Strip 来换取适配。
- 不得逐页散落新的缩放常数；窗口、壳层、字体和 icon 尺度必须来自 `NoonmarkMacUIContract` 的唯一当前 token。
- 不得把归档 HTML 原型作为视觉 oracle，也不得自行生成 golden reference。

## 真实 App 验收

- CGWindow 必须报告唯一主窗口 `1000 × 768pt`。
- 真实 `.app` E2E 必须覆盖 Day Todo、任务池、未来计划、未完成、已完成、日历、烛龙、设置、任务详情、分类管理浮窗和 English 文案。
- 截图必须逐页检查文字截断、控件碰撞、横向溢出和视觉密度；运行日志不得出现 fatal、assertion 或 persistence failure。
- 任务池真实 UI 几何探针必须在 `1000×768pt` 下确认每个可见任务标题和分类 badge 都达到其文字所需宽度，且三项排期按钮保留完整文案；只验证 view 存在或截图尺寸不算通过。
- resize probe 必须验证 `960 × 720pt` 最小尺寸仍可用，并能从最小尺寸恢复默认尺寸。
